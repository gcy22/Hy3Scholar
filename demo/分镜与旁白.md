# Hy3Scholar 两分钟功能 Demo

- 输出规格：中文旁白，1920×1080，30 FPS，H.264/AAC MP4；
- 时长限制：严格小于 120 秒；
- 内容：项目背景、技术原理、多源检索、OA PDF 校验、Dataset v0、人工审核和七维评测；
- 数据：画面统计来自本地真实构建与评测结果；
- 隐私：不展示 API Key、完整本地路径、个人身份信息或论文全文。

## 分镜

1. 标题与功能范围；
2. 开放式综述的事实、引用与覆盖问题；
3. Evidence-grounded 双向核验原理；
4. OpenAlex、Crossref、arXiv 多源发现与去重；
5. 仅开放获取 PDF 的下载和有效性验证；
6. Hy3 自动生成摘要、问答、难例和反例；
7. 人工查看原文证据并审核样本；
8. 七维评分、Claim 级错误定位与改进建议；
9. 可信评测闭环与项目地址。

旁白原文保存在 `narration.json`。运行 `build_demo.ps1` 可重新生成视频。
